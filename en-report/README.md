# English Report Template

This repository contains the official **LyX** template for the Capstone Project Report _(Projet de Fin d'Études)_ in English, tailored for students in the Electrical Engineering Department at ISET Bizerte.

Writing a report is demanding enough without having to manage margins, fonts, or formatting yourself. We created this template with **LyX** to handle the layout for you. Built on the powerful **LaTeX** typesetting engine, it automates the heavy lifting—line spacing, section numbering, automatic cross-references, and bibliography formatting—so you can concentrate fully on your content.

The core philosophy is simple: **WYSIWYM** *(What You See Is What You Mean)*. You indicate the role of an element _(e.g., section title, figure caption, code block, etc.)_, and **LyX** automatically manages its presentation. The result is a clean, consistent, publication-ready document without any manual style adjustments.
