# English Report Template

This repository contains the official LyX template for the Capstone Project Report _(Projet de Fin d'Études)_ in English, tailored for students in the Electrical Engineering Department at ISET Bizerte.

Writing a report is demanding enough without the added frustration of wrestling with margins, fonts, and heading styles. **LyX** completely eliminates that burden. Built on top of the powerful **LaTeX** typesetting engine, it automates the heavy lifting—handling line spacing, section numbering, cross-references, and bibliography formatting automatically. This allows you to focus entirely on what matters most: your technical content.

The core philosophy is simple: **WYSIWYM** *(What You See Is What You Mean)*. You define what an element is (a section heading, a figure caption, or a block of code), and **LyX** takes care of how it looks. The result is a flawlessly formatted, publication-ready document without ever needing to touch a style menu.
