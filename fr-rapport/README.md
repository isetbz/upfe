# Modèle de rapport

Ce dépôt contient le modèle **LyX** officiel pour le rapport de Projet de Fin d'Études (PFE), spécialement conçu pour les étudiants du Département Génie Électrique de l'ISET Bizerte.

Nous avons créé ces modèles avec **LyX** pour prendre en charge la mise en page à votre place. Plus besoin de vous soucier des marges, des polices ou du style : **LyX** gère la composition **LaTeX**, l’interlignage, la numérotation des sections, les renvois automatiques et la bibliographie, afin que vous puissiez vous concentrer pleinement sur le contenu.

La philosophie est simple : le **WYSIWYM** *(What You See Is What You Mean — Ce que vous voyez est ce que vous voulez dire)*. Vous indiquez le rôle d’un élément _(e.g., titre, légende, bloc de code, etc.)_, et **LyX** se charge automatiquement de sa présentation. Le résultat : un document propre, uniformisé et prêt à être publié, sans aucune manipulation de style manuelle.
